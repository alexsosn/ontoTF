# TFont v0.1.1

v0.1.1 is a **metadata-only** packaging patch over v0.1.0.

## Changed

The Python distribution now publishes the reviewed PEP 639 mixed-license metadata:

- `License-Expression: MIT AND CC-BY-3.0`;
- root `LICENSE`;
- bundled OLiA `LICENSE.data`;
- bundled OLiA `ATTRIBUTION.txt`.

The v0.1.0 GitHub wheel was built before this metadata correction. Its tag and asset remain unchanged as historical output; v0.1.1 is the supported replacement for new installations.

## Unchanged semantic/runtime scope

There is no new semantic or runtime functionality in this patch. The supported v0.1 contract remains the exact OLiA `Noun` slice for the same pinned ETCBC **BHSA**, **Syriac**, and **ExtraBiblical** corpus revisions, using already-loaded Text-Fabric / Context-Fabric APIs and the same bundled OLiA revision.

Production profile/resource versions remain 0.1.0 because their semantic content did not change.

## Installation

Download `tfont-0.1.1-py3-none-any.whl` from this GitHub release and install the downloaded local file:

```sh
python -m pip install ./tfont-0.1.1-py3-none-any.whl
```

`pip install tfont` is **not** a supported PyPI installation instruction; this release is distributed through GitHub. Third-party corpus data are not bundled or downloaded by TFont and retain their upstream licenses.

## Verification

The release candidate is built and tested on Python 3.10 and 3.12. CI verifies wheel and sdist PEP 639 metadata, license/attribution bytes, absence of TF/MQL corpus payload, fresh-wheel installation outside the source checkout, the existing v0.1 Noun acceptance path, and the full repository suite.
