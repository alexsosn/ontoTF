authenticate a reviewer, and a past report cannot prove current approval.

and content integrity do not establish the producer's policy or scholarly truth.

recommended handoff. GitHub docs describe OIDC/attestations-write permissions and
actions/attest@v4; GitHub CLI verifier provides repository, signer-workflow,

workflow/base code, not merely any workflow in the repository.
